# 万物有灵 · 山海异兽志 · 扩展版 v2

2026-10-21。24 位有《山海经》原文依据的异兽；宣纸、工笔、朱砂与石青风格。原生 HTML/CSS/JS，单 HTML 入口，无构建步骤。

## 启动

Windows 双击 `启动作品.cmd` 或 `Start-Shanhai.cmd`。仅使用系统 PowerShell，监听本机 127.0.0.1，自动选择 8848—8889 端口。保持窗口打开，结束按 Ctrl+C。无需 Python、Node 或管理员安装。系统策略限制脚本时可使用已有静态 HTTP 服务器，不必修改安全策略。

若已有 Python，在作品目录运行 `python -m http.server 8848`，打开 `http://127.0.0.1:8848/`。直接打开 index.html 可以浏览；丹青工坊建议在 HTTP 下使用。

## 使用功能

1. 弧形画卷：自动左移、暂停、拖拽、惯性、键盘操作及减少动态偏好。
2. 24 位图鉴：类别、篇章、古籍形态组合筛选；名称、特征和拼音检索；新入卷 12 位入口。
3. 原文阅读：原文、释义、山名、艺术演绎说明与出处外链；设备支持时语音朗读。
4. 循卷寻踪：六篇章导航，查看山名与遇见状态，一键筛选本篇角色。
5. 异兽对读：选两位比较图像、原文与形态，交换角色，下载 Markdown 笔记。
6. 山海识灵：随机五题，回答后显示原文依据；计分、最佳成绩、错题本及错题重练。
7. 个人藏卷与足迹：收藏、去重的已遇见角色、进度筛选，JSON 导出与合并导入。
8. 丹青工坊：固定矿物色映射、Sobel 墨线、确定性纸纹、原图对照及 1200×1660 PNG 藏页导出。
9. 手机快捷导航直达图鉴、寻踪、对读、识灵、工坊与出处。

收藏、足迹和错题保存在当前浏览器。换设备前可下载 JSON；导入为合并，未知角色忽略，格式错误不改原数据。导入文件最大 256 KiB。此功能不是账号或云同步。语音依赖设备服务；古籍外链需要网络。主体浏览、答题和图像处理使用本地静态文件。

## 资料与素材

`process/creature-research.json` 为 24 条完整资料；`扩展考据_v2.md` 补充本轮形态依据；`素材与生成记录_v2.json` 记录每图提示词、出处和 SHA-256。24 幅展示图在 assets/generated，原始 PNG 在 process/originals。原有弃用候选另存，未进入正式网页。

插画为 AI 辅助艺术演绎，不是古图、真实生物照片、角色动作视频或三维模型。用户提出项目方向、交互参考和风格决策，资料、插画、代码与材料均有 AI 辅助；参赛者实际贡献须据实填写。

## 开发与验证

直接运行根目录 index.html 或使用启动器，不需要依赖安装。修改作者源后运行 `python scripts/build_site.py`；Python 仅在重建时需要。`python scripts/check_site.py` 核对素材并抽取 JS，随后可执行 `node --check output/site-check.js`。

浏览器验收使用已安装的 Playwright CLI。先在仓库根目录启动 HTTP 服务（8848 端口），再运行 `playwright-cli -s=shanhai open http://127.0.0.1:8848/` 和 `playwright-cli -s=shanhai run-code --filename=tests/browser_checks.js`。测试会向 output/playwright/regression 写截图及实际导出文件，并在该测试浏览器中重建本地测试状态，不涉及真实用户数据。

仓库包含 24 幅正式插画的原始 PNG、展示 WebP、字体许可、文献及提示词记录。竞赛身份材料和本机工作区历史没有纳入。AI 使用、第三方资源与实际验证范围见 docs。未指定软件开源许可，公开使用或再分发前请确认相应授权与生成服务条款。
