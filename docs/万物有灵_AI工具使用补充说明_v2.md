# AI 工具使用补充说明 v2

作品：万物有灵 · 山海异兽志。AI 使用状态：已使用。

Codex 辅助资料检索、原文整理、释义、提示词、网页代码、算法、集成、测试与材料制作。内置 imagegen 根据文字生成 24 幅入选插画，另保留 1 幅文献依据不符的弃用候选。底层图像模型版本未披露，本说明不猜测模型名。没有额外付费 API Key 调用、视频生成、真人声音克隆或第三方图像输入。

角色先据原文提取形体、色彩和足翼尾角等约束，再按统一工笔矿物色风格生成。展示文件为 WebP，原始 PNG 保留。图像经 AI 代理视觉核查，最终由参赛者复核，不冒充专家审定。

丹青工坊在本地进行固定色板映射、Sobel 墨线及确定性纸纹处理，不调用在线生成模型。识灵题目依据现有词条特征组成，不接入大模型聊天。语音使用设备 Web Speech API，没有预制配音。

用户提出目标、弧形卡片参考、山海经风格及扩展角色功能需求。参赛学生的独立工作、线下审核、团队分工和后续修改应由参赛者按实际情况填写。不编造学生独立原创、人工评分、用户研究、比赛提交或获奖结果。

网页、详情、导出藏页标明 AI 辅助和艺术演绎。素材记录附提示词、SHA-256 与出处；测试记录为真实自动化结果。备份示例为测试数据，不是用户画像。
