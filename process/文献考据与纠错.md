# 万物有灵：文献考据与视觉边界

核查日期：2026-10-21。所引《山海经》古籍正文为公有领域文本；在线底本采用维基文库。引文节录统一整理部分字形、标点，未复制现代译文。词条释义由本项目据原文重新整理。

## 原文入口

- [南山经](https://zh.wikisource.org/wiki/山海經/南山經)：招摇之山的狌狌、杻阳之山的鹿蜀、青丘之山的九尾狐。
- [西山经](https://zh.wikisource.org/wiki/山海經/西山經)：昆仑之丘的陆吾和钦原、章莪之山的毕方、天山的帝江、翼望之山的讙。
- [北山经](https://zh.wikisource.org/wiki/山海經/北山經)：发鸠之山的精卫、单张之山的诸犍与白鵺。
- [海外北经](https://zh.wikisource.org/wiki/山海經/海外北經)：钟山之神烛阴。

## 本轮纠错

| 条目 | 旧稿或候选中的问题 | 本次采用的形态依据 |
|---|---|---|
| 陆吾 | 误加八足 | 虎身九尾、人面虎爪；原文不记八足 |
| 钦原 | 误作人面青鸟、传信使者 | 状如蜂（底本文字作蠭），大如鸳鸯 |
| 毕方 | 误把独足写成独翼 | 状如鹤、一足、赤文青质、白喙 |
| 诸犍 | 与九尾狐等形态混淆 | 豹身长尾、人首牛耳、一目；尾仅一条 |
| 白鵺 | 候选误作西山经亶爰之山黄身鸟 | 北山经单张之山；雉形、文首、白翼、黄足 |
| 狌狌 | 混入水灾征兆与外文残片 | 如禺、白耳、伏行人走 |
| 烛阴 | 混写不同篇章 | 使用海外北经的钟山条目，区分大荒北经烛龙表述 |
| 白泽、蜚蠊 | 不适合直接沿用为本卷山海经词条 | 保留旧稿文件，正式图鉴改为有明确篇章依据的九尾狐、精卫等条目 |

## 画面和古籍的关系

本作不是古籍插图复原。山川、日月、植物、火焰、面容细节、姿态及原文未指定的颜色，为艺术演绎。鹿蜀白首赤尾虎纹、毕方独足青质白喙、帝江无面六足四翼、讙单眼三尾等识别约束来自原文。

部分艺术配景不应被理解为对应山名的真实生态环境。例如章莪之山、单张之山在底本中记为无草木，插画中的风格化背景仅作为艺术配景。

本轮完成代理视觉检查，不冒称古籍学者审定或参赛学生亲自评分。提交前请参赛者自行读原文并能解释图像与原文的对应。古籍中的疗疾、禳除和食用记述仅作文化记录。
